Reset password Permette di impostare una password di default per un utente

Se un utente dimentica la propria password, può chiedere all'amministratore del torneo di impostare una di deafult. L'utente può utilizzare tale password per riaccedere al sistema e impostarne una nuova.

Ne l'amministratore ne il fornitore del sistema sono in grado di ripristinare la vecchia password dato che è criptata ma possono resettarla, renderla vuota o impostarne una di default che poi l'utente cambia con una propria.
