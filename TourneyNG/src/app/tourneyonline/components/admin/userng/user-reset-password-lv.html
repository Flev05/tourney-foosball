Reset password Permette di impostare una password di default per un utente

Utente [{{loggedUsername}}]

Se un utente dimentica la propria password, può chiedere al proprietario del sistema o all'amministratore del torneo di impostarne una di deafult.

L'utente può cpsì utilizzare tale password per riaccedere al sistema e impostarne una sua nuova.

Ne l'amministratore ne il fornitore del sistema sono in grado di ripristinare la vecchia password dato che è criptata, possono solo resettarla, renderla vuota o impostarne una di default che poi l'utente cambia con una propria.
